# 위치 예측 및 실종 위험도 참고 분석 실행 방법

위치 예측은 브라우저의 TensorFlow.js 모델이 실행하고, 위험도 참고 분석은 로컬 Python 서버가 실종 시각의 지역 기상을 조회한 뒤 OpenAI Responses API로 생성합니다.

OpenAI API 키는 브라우저 코드에 넣지 않습니다. 프로젝트 루트의 `.env` 파일을 로컬 Python 서버만 읽습니다.

## 최초 설정

프로젝트 루트의 `.env` 파일을 열어 `OPENAI_API_KEY=` 뒤에 발급받은 키를 입력합니다.

~~~dotenv
OPENAI_API_KEY=sk-여기에_발급받은_키
OPENAI_MODEL=gpt-5.6-sol
~~~

`.env`는 `.gitignore`에 등록되어 있으므로 저장소에 포함하지 마세요. `OPENAI_MODEL`은 선택 사항이며 기본값은 `gpt-5.6-sol`입니다.

## 실행

1. 프로젝트 최상위 폴더의 **run_frontend.bat**를 더블클릭합니다.
2. 브라우저에서 테스트 화면이 열립니다.
3. 정보를 확인하거나 수정한 뒤 **예상 발견 위치 계산**을 누릅니다.
4. 지도 아래에서 실제 지역 기상, 경과 시간, AI 위험도 참고 점수와 등급을 확인합니다.
5. 종료할 때 함께 열린 검은색 창을 닫습니다.

## 장소 검색

1. **실종 장소**에 공공장소 또는 지역명을 입력합니다.
2. **장소 검색** 버튼을 누릅니다.
3. 검색 결과 중 정확한 장소를 선택합니다.
4. 위도와 경도가 자동으로 설정됩니다.
5. 예측 결과에는 예상 좌표와 가까운 지역명이 함께 표시됩니다.

주소 검색에는 공개 OpenStreetMap 데이터가 사용됩니다. 기상 조회에는 Open-Meteo가 사용됩니다. 실제 개인 주소나 불필요한 민감정보는 입력하지 마세요. OpenAI에는 정확한 좌표와 장소명 대신 경과 시간, 대상자 특성, 장소 유형, 기상 요약만 전달합니다.

직접 접속할 때의 주소는 다음과 같습니다.

~~~text
http://127.0.0.1:5500
~~~

기존 정적 서버가 5500 포트를 사용 중인 경우 새 서버가 5501 이후의 빈 포트로 자동 전환한 뒤 올바른 주소를 브라우저에서 엽니다.

## 프론트 폴더

~~~text
frontend
├─ index.html
├─ css
│  └─ styles.css
├─ js
│  ├─ app.js
│  └─ map-view.js
└─ model
   ├─ model.json
   ├─ group1-shard1of1.bin
   └─ preprocessing.json
~~~

프로젝트 루트의 `server.py`가 정적 파일과 `/api/risk-assessment` API를 함께 제공합니다. 별도 Python 패키지는 필요하지 않습니다.

TensorFlow.js, 지도, 웹 글꼴, 기상 API, OpenAI API를 사용하므로 테스트할 때 인터넷 연결이 필요합니다.

## 안전상 주의

위험도는 OpenAI가 입력 정보와 기상을 바탕으로 생성한 0~100점의 실험적 참고 지표이며, 검증된 의학·통계 점수가 아닙니다. 점수와 관계없이 즉시 112에 신고하고 전문 구조기관의 지시를 따라야 합니다. 이 결과로 수색 우선순위나 중단 여부를 결정하면 안 됩니다.
